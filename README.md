# JARVIS — дневник дня (PWA)

Персональный «ДЖАРВИС» для телефона: напоминает вести дневник дня по временным слотам и хранит историю локально на устройстве, в стиле «голографический синий».

## Что умеет

- Напоминания «по кусочкам» через Web Push (по часам после каждого слота времени).
- Таблица: время / дело / удовольствие (0–10) / важность (0–10) + «настроение дня».
- История по дням (листание) и выгрузка в JSON/CSV.
- Данные хранятся только на телефоне (IndexedDB), без аккаунта и синхронизации.

## Запуск на ноутбуке (локально)

Нужен установленный **Node.js** (LTS, версия 18+).

```bash
npm install        # один раз — поставить зависимости
node --test        # (необязательно) прогнать тесты
npx serve .        # запустить локальный сервер
# или без npx: python -m http.server
```

Открыть в браузере `http://localhost:3000` (или порт, который показал сервер).

Что работает локально: заполнение таблицы, листание дней, история, выгрузка JSON/CSV.

Что **не** работает локально: push-уведомления — для них нужен деплой на Vercel (HTTPS + сервер + реальный телефон). Тап по уведомлению локально проверить нельзя.

## Деплой на Vercel

**Коротко, как это устроено:**

- **Проект в Vercel создаётся автоматически** — в момент импорта репозитория (это и есть «проект» = приложение + настройки).
- **Проект надо привязать и к хранилищу, и к git**: к git — самим импортом репозитория; к **Upstash Redis** — подключением хранилища к проекту (см. шаг 4).
- **Деплой из git — основной способ**: после первого импорта каждый `git push` в `main` передеплоивает автоматически.

**Шаги:**

1. Войти на [vercel.com](https://vercel.com) → **Add New → Project** → импортировать репозиторий `AlexeySushkov/JARVIS` (Vercel попросит доступ к GitHub — разрешите).
2. Vercel сам определит проект (статический сайт + serverless-функции `api/`), сборка не нужна — просто **Deploy**.
3. Задать **Environment Variables** (**Settings → Environment Variables**). Значения лежат в локальном файле `.env` (в git не попадает):
   - `VAPID_PUBLIC_KEY` — публичный ключ (уже вшит в `app.js`, но продублируйте для сервера);
   - `VAPID_PRIVATE_KEY` — приватный ключ (никому не передавайте);
   - `VAPID_SUBJECT` — `mailto:you@example.com`;
   - `CRON_SECRET` — секрет для cron, защищает `/api/notify`.
4. Подключить **Upstash Redis**: **Project → Storage → Connect Store** → выбрать созданное Upstash Redis. Переменные `UPSTASH_REDIS_REST_URL` и `UPSTASH_REDIS_REST_TOKEN` подтянутся автоматически (код уже использует `@upstash/redis`).
5. Настроить напоминания: они приходят через **GitHub Actions** (файл `.github/workflows/notify.yml` дёргает `/api/notify` каждый час). Для этого добавьте секрет `CRON_SECRET` в GitHub: репозиторий → **Settings → Secrets and variables → Actions → New repository secret** (имя `CRON_SECRET`, значение из `.env`). Точность напоминаний — до часа.

**Альтернатива — через CLI:**

```bash
npm i -g vercel
vercel login
vercel deploy --prod
```

## Установка на телефон дочери (Android)

1. Открыть URL приложения в Chrome.
2. Меню → **Добавить на главный экран** (Add to Home Screen).
3. Открыть приложение с иконки и разрешить уведомления.
4. Напоминания приходят в начале часа; тап по уведомлению открывает нужный слот.

## Данные и выгрузка

История хранится только в браузере телефона. Кнопки **JSON / CSV** в шапке скачивают всю историю.

## Архитектура

- `index.html`, `styles.css`, `app.js` — фронтенд (без фреймворков и сборки).
- `lib/*` — чистая логика (слоты, даты, расписание, хранилище, выгрузка, шов под LLM).
- `api/subscribe.js`, `api/notify.js` — serverless-функции Vercel (хранение push-подписок в Upstash Redis, отправка напоминаний).
- `sw.js` — service worker (кэш + показ уведомлений).
- `.github/workflows/notify.yml` — планировщик напоминаний (каждый час, GitHub Actions).
