# JARVIS — дневник дня (PWA)

Персональный «ДЖАРВИС» для телефона: напоминает вести дневник дня по временным слотам и хранит историю локально на устройстве, в стиле «голографический синий».

## Что умеет

- Напоминания «по кусочкам» через Web Push после каждого слота времени.
- Таблица: время / дело / удовольствие (0–10) / важность (0–10) + «настроение дня».
- История по дням (листание) и выгрузка в JSON/CSV.
- Данные хранятся только на телефоне (IndexedDB), без аккаунта и синхронизации.

## Локальная разработка

```bash
npm install
node --test          # тесты
npx serve .          # или: python -m http.server
```

Открыть `http://localhost:3000` (или порт, который показал сервер).

## Деплой на Vercel

1. Установить Vercel CLI и войти в аккаунт:
   ```bash
   npm i -g vercel
   vercel login
   ```
2. Создать хранилище для push-подписок. Внимание: `@vercel/kv` помечен устаревшим — если в аккаунте Vercel нет KV, создайте **Upstash Redis** через Vercel Marketplace (**Storage → Create → Redis/Upstash**); тогда импорт в `api/*.js` надо заменить с `@vercel/kv` на `@upstash/redis` (могу сделать по запросу).
3. Задать секреты в проекте Vercel (**Settings → Environment Variables**):
   - `VAPID_PUBLIC_KEY` — публичный ключ (уже вшит в `app.js`, но продублируйте для сервера);
   - `VAPID_PRIVATE_KEY` — приватный ключ (см. ниже);
   - `VAPID_SUBJECT` — `mailto:you@example.com`;
   - `CRON_SECRET` — секрет для cron (см. `.env`), защищает `/api/notify`.

   Ключи уже сгенерированы и лежат в локальном файле `.env` (в git не попадает). Приватный ключ никому не передавайте.
4. Задеплоить:
   ```bash
   vercel deploy --prod
   ```
   Расписание напоминаний настроено в `vercel.json` (cron каждые 5 минут → `/api/notify`). Внимание: бесплатный тариф Vercel может ограничивать частоту cron — после деплоя убедитесь, что cron реально запускается раз в ~5 минут; если нет, потребуется внешний планировщик (например GitHub Actions).

## Установка на телефон дочери (Android)

1. Открыть URL приложения в Chrome.
2. Меню → **Добавить на главный экран** (Add to Home Screen).
3. Открыть приложение с иконки и разрешить уведомления.
4. Напоминания начнут приходить после ближайшего слота; тап по уведомлению открывает нужный слот.

## Данные и выгрузка

История хранится только в браузере телефона. Кнопки **JSON / CSV** в шапке скачивают всю историю.

## Архитектура

- `index.html`, `styles.css`, `app.js` — фронтенд (без фреймворков и сборки).
- `lib/*` — чистая логика (слоты, даты, расписание, хранилище, выгрузка, шов под LLM).
- `api/subscribe.js`, `api/notify.js` — serverless-функции Vercel (хранение push-подписок в KV, отправка напоминаний).
- `sw.js` — service worker (кэш + показ уведомлений).
- `vercel.json` — cron-расписание.
